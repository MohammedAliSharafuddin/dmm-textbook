Dataset Overview

The teaching pack uses a small number of datasets repeatedly. Reusing the same files helps you spend more time interpreting results and less time searching for a new dataset each chapter.

The table below lists them.

Dataset Rows x columns Main use Chapters Software
DMM_Teaching_Data_Full.csv 200 x 26 Core teaching file for most statistical weeks 1, 2, 4, 5, and 9 to 15 JASP or PocketStat, Excel, R
DMM_Coursework_Data.csv 100 x 28 Assessed coursework file with marketing spend and customer acquisition Coursework and Chapter 9 demo JASP or PocketStat
Week6_Porter_Scenario_Data.csv 40 x 10 Porter’s Five Forces ratings and strategic option practice 6 Google Sheets and discussion
Week7_RBV_Resource_Data.csv 40 x 7 VRIO and resource advantage practice 7 Google Sheets and discussion
Week3_Decision_Tree_Data.csv 100 x 6 Expected value decision practice 3 Google Sheets
Week3_CPM_Task_Data.csv 8 x 6 PERT and CPM timing practice 3 Google Sheets
Week3_Gantt_Data.csv 8 x 8 Project schedule and Gantt practice 3 Google Sheets
Week3_Probability_Basics_Data.csv 100 x 4 Event counting and probability practice 3 Google Sheets

The dictionary files in data/dictionary/ describe the recommended JASP type for each variable. Use those files when JASP imports a CSV and marks every column as scale. PocketStat infers types on load, so the same care applies: check that an ordinal rating has not been read as a scale measurement before running a test.

Derived teaching datasets

The revised project also includes derived teaching datasets for examples that need a cleaner multi-context structure. The derived teaching datasets below are used where a concept needs a cleaner multi-context structure.

Dataset Main use Contexts
week04_single_sample_inference_demo.csv Benchmark testing, confidence intervals, one-sample proportion Business, health service, public service, education
week05_group_comparison_anova_demo.csv Independent groups, paired logic, ANOVA, Tukey, Kruskal-Wallis Retail, clinic, service centre
week12_cleaned_spreadsheet_factor_prep.csv Spreadsheet cleaning, reverse coding, composite scoring, pivot summaries Central, North, and South branches of one organisation
week13_15_factor_sem_teaching_demo.csv EFA, CFA, SEM and PLS-SEM teaching examples One organisation, three constructs: capability, strategy, and performance

Use the original raw datasets for continuity with the module. Use the derived datasets when a concept requires a focused example with clear group structure, scale items, or latent constructs.
