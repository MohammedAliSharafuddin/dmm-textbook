Running the analysis, and chapter reference

Keywords

probability in LibreOffice Calc, expected value spreadsheet, BINOM.DIST, critical path spreadsheet, Gantt chart in LibreOffice Calc, Gantt chart in Google Sheets, decision note, formula review

Parts 1 to 3 calculated every probability, expected value and critical path manually. A spreadsheet repeats the same arithmetic for all 100 records, all 50 scenarios and all 8 tasks, displaying every calculation step in a cell for verification.

You make the remaining judgements: selecting the appropriate denominator, determining the maximum loss the team can absorb and establishing the acceptable level of risk for a promised date. This page outlines the spreadsheet formulas and translates the results into statements suitable for management reporting.

The key terms and the formula review at the foot cover all three parts, with every term linked back to the section that defines it.

Running the analysis

Google Sheets and LibreOffice Calc use the same formulas for everything in this chapter, apart from references to another sheet, so one set of instructions serves both. LibreOffice is free to install from libreoffice.org. Where the menus differ, the steps specify the correct menu for each application. The tutorial guides you through these procedures step by step.

Load the four files

Google Sheets: Create a blank spreadsheet. Choose File, then Import, then Upload and pick the CSV file. Set Import location to Insert new sheet(s). Repeat for the other three files, so each sits on its own tab.

LibreOffice Calc: Open the first CSV file and tick Comma in the Text Import dialogue. To add each of the others as a sheet, choose Sheet, then Insert Sheet from File. Save the workbook as .ods or .xlsx, because a CSV file keeps only one sheet.

Check the row counts: 100 records in the probability file, 100 rows in the decision tree file and 8 tasks in each of the CPM and Gantt files. Each file has its column names in row 1, so the data start in row 2.

Probabilities from records

The probability file has Attendance in column B, Ticket_Type in column C and Payment_Method in column D.

COUNTIF counts rows meeting a single condition, while COUNTIFS counts rows meeting all listed conditions. The denominator determines the probability type, as in part 1: COUNTA of the whole column for a marginal or joint probability, and COUNTIF of the condition for a conditional one.

A pivot table generates an entire contingency table simultaneously. In Google Sheets choose Insert, then Pivot table. In LibreOffice Calc choose Insert, then Pivot Table. Place Payment_Method in Rows, Attendance in Columns and Event_ID in Values, summarised by COUNTA in Google Sheets or Count in LibreOffice Calc. The result is Table 3.4.

Expected value and risk

The decision tree file has Option in column B, Probability_Success in C, Probability_Failure in D, Payoff_Success in E and Payoff_Failure in F. Add two columns.

Extend both formulas down to row 101. The standard deviation formula uses the two-outcome shortcut from part 2, where \(p(1 - p)\) is expressed as C2*D2 because the failure probability is \(1 - p\).

To summarise each option across the 50 scenarios:

  • Mean expected value: =AVERAGEIF(B2:B101, "Local_Vendor", G2:G101) gives 3,711.82.
  • Largest loss: =MINIFS(F2:F101, B2:B101, "Local_Vendor") gives -1,993.70.

Change "Local_Vendor" to "International_Vendor" for the other option: 8,317.91 and -3,930.59.

Binomial probabilities

BINOM.DIST requires four arguments: the number of successes, the number of trials, the probability of success and FALSE for exactly that number or TRUE for that number or fewer.

  • Exactly 2 of 3 attend: =BINOM.DIST(2, 3, 0.83, FALSE) gives 0.3513.
  • More than 105 of 120 attend: =1 - BINOM.DIST(105, 120, 0.83, TRUE) gives 0.0710.

PERT and the critical path

The CPM file has Task_Name in column B, Predecessors in C and the optimistic, most likely and pessimistic durations in D, E and F. Add seven columns.

The MAX and MIN formulas reference specific cells because each task has unique predecessors. Staff_Briefing in row 8 depends on rows 4, 5, 6 and 7, so its ES is =MAX(J4, J5, J6, J7). Catering_Arrangement in row 6 precedes rows 7 and 8, so its LF is =MIN(K7, K8). Final_Rehearsal in row 9 is the last task, so its LF is =J9.

Columns J and K use the most likely duration in column E. To execute the passes using PERT durations, change column E to column G in both formulas. The critical path remains unchanged while the finish time changes from 16 to 16.0.

Gantt chart

A Gantt chart in a spreadsheet is a stacked bar chart with an invisible first series. The first series offsets each bar to its start day, and the second series forms the visible bar.

  1. In the Gantt sheet, add a column headed Offset with =C2 - 1 in row 2, filled down. Column C is Start_Day, so Offset is the number of whole days before the task starts.
  2. Select the Task_Name, Offset and Duration_Days columns.
  3. Google Sheets: Choose Insert, then Chart. In the chart editor set Chart type to Stacked bar chart. Under Customise, then Series, choose the Offset series and set its Fill opacity to 0%.
  4. LibreOffice Calc: Choose Insert, then Chart, and pick Bar with its Stacked variant. On the Data Series page, move Offset above Duration_Days, because Calc orders the series by column. Double-click an Offset bar and set Area to None. Then double-click the task names, open the Scale tab and tick Reverse direction, so that the first task appears at the top.
  5. Format the critical tasks with a distinct colour and add “(critical)” to their names to ensure the chart remains legible in greyscale.

Browser tools for checking your working

Three free browser tools load the data files for this chapter and verify the manual calculations and spreadsheet outputs. Each tool is embedded on its relevant page and opens in a new tab via the links below.

  • Probability explorer: contingency tables with joint, marginal and conditional probabilities, the addition rule and an independence check. Framed in part 1.
  • Decision tree calculator: the tree and expected values for any of the 50 vendor scenarios, and trees of your own. Framed in part 2.
  • CPM/PERT and Gantt planner: both passes, slack, the critical path, the deadline probability and a Gantt chart checked against the Gantt file. Framed in part 3.

Checking a probability in JASP or PocketStat

JASP and PocketStat can verify the counts from part 1, while all other results in this chapter require the spreadsheet.

JASP: Open Week3_Probability_Basics_Data.csv. Choose Frequencies, then Contingency Tables. Move Payment_Method into Rows and Attendance into Columns. Under Cells, tick Row percentages. Each row percentage is a conditional probability multiplied by 100: the Cash row reads 76.7 per cent attended.

PocketStat: Load the same file and choose Descriptive statistics for Attendance. A categorical variable gives a frequency table with counts and percentages: 83 attended, 83.0 per cent.

Reporting the result

Each tool in this chapter produces a numerical result that a manager must translate into a descriptive statement. An effective statement specifies the figure, its source, its interpretation and the recommended action.

For a probability: State the denominator in words so the reader knows which group the figure describes.

Among the 30 registered people who paid in cash, 23 attended, a rate of 77 per cent against 83 per cent overall. Cash payers will receive a reminder message three days before the event.

For an expected value: Provide the expected values, followed by the worst outcome and its probability, and finally the recommended choice and its condition.

Booking the international vendor gives an expected profit of 9,128 USD, against 4,665 USD for the local vendor. The international vendor delivers late about once in 6 contracts, and a late delivery costs 2,299 USD. That loss is within the team’s reserves, so the international vendor is recommended.

For attendance: Provide the expected number and the relevant risk regarding room capacity or catering orders.

Of the 120 people registered, about 100 are expected to attend. The room seats 105, and the chance that more than 105 attend is about 7 per cent, so a waiting list will be kept.

For a schedule: State the finishing date, the critical tasks and the probability of meeting the deadline.

Preparation takes 16 working days. The venue booking, catering, AV setup, staff briefing and final rehearsal are critical, and any delay to them delays the event. The team has about a 96 per cent chance of being ready within 18 working days, and 18 is the date to promise the venue.

The decision note

The decision note in the tutorial integrates all three tools. Write it in four parts:

  1. The recommendation, in the first sentence.
  2. The evidence, one figure per tool, each with its denominator or its source file.
  3. The risk, the one outcome most likely to hurt, with its probability.
  4. The action, what the team does next and by when.

Round probabilities to two decimal places or to whole percentages, money to the nearest dollar and durations to one decimal place. Cite the source file for each figure to allow verification by another analyst.

Chapter review

A probability from records is a count divided by the total number of relevant cases, and the question phrasing determines the appropriate denominator. Joint probabilities occupy the cells of a contingency table, marginal probabilities appear in the margins and conditional probabilities restrict the denominator to a single row or column. The addition rule prevents double counting, while the multiplication rule links events along a probability tree. An expected value weights each payoff by its probability, and a risk review evaluates the probability of a loss, the worst outcome and the standard deviation alongside the expected value. A decision tree rolled back from right to left identifies the optimal option, while subsequent decisions can alter earlier choices. The binomial model counts successes among independent trials. PERT converts three estimates into an expected duration and a variance. The forward and backward passes calculate the slack and the critical path, and the variance of the path provides the probability of meeting a deadline. A Gantt chart displays the schedule on a calendar and requires verification against the network.

Key terms

Every term links to its defining section, and the three groups correspond to the three parts of the chapter, making this section function as a revision guide.

Part 1, probability from records

Decision under uncertainty
a choice made before its outcome is known
Probability
a number from 0 to 1 stating how likely an event is
Event
an outcome that can be counted in the records
Complement
everything outside an event, with probability \(1 - P(A)\)
Contingency table
counts of cases in each combination of two categorical variables
Joint probability
the probability that two events occur together
Marginal probability
the probability of one event, from a table’s margin
Conditional probability
the probability of one event among the cases of another
Addition rule
\(P(A \text{ or } B) = P(A) + P(B) - P(A \text{ and } B)\)
Mutually exclusive
unable to occur in the same case
Independent events
events where the occurrence of one does not alter the probability of the other
Multiplication rule
\(P(A \text{ and } B) = P(B) \times P(A \mid B)\)
Probability tree
a diagram of events in the order they occur, with a probability on each branch

Part 2, expected value and decision trees

Random variable
a quantity whose value depends on an uncertain event
Probability distribution
every value of a random variable, with its probability
Expected value
the probability-weighted average of the possible values
Expected monetary value
an expected value measured in money
Risk review
the probability of a loss, the worst outcome and the spread, evaluated alongside the expected value
Decision tree
a diagram of options, chance events and payoffs
Decision node
a square, where the manager selects a branch
Chance node
a circle, where an uncertain event determines the outcome
Rolling back
calculating the value of a tree from the payoffs back to the first decision
Binomial model
the distribution of successes in \(n\) independent trials with the same \(p\)

Part 3, project time

Predecessor
a task that must finish before another can start
Critical path method (CPM)
scheduling by the longest chain of linked tasks, also called critical path analysis (CPA)
PERT
an expected duration and variance from three estimates
Forward pass
finding the earliest start and finish of each task
Backward pass
finding the latest start and finish of each task
Slack
the number of days a task can be delayed without delaying project completion, also called float
Critical path
the chain of zero-slack tasks that determines the finishing date
Gantt chart
a schedule drawn as bars against a calendar
